Executive Summary

An autonomous pipeline researched each app from official documentation, scored its own confidence per field, re-verified weak answers with an independent second pass, and had its output audited by hand on a stratified sample. Verdicts come from a deterministic rule engine — the model only extracts against evidence, and fields without supporting evidence are preserved as UNKNOWN rather than inferred.

OAuth 2.0 is the dominant authentication pattern — 53 of 100 apps support it, and 60 offer simple API keys, so most integrations need no bespoke auth work.

92% of apps are fully self-serve: a developer can obtain credentials without sales calls or partner approval, enabling same-day integration builds.

Agent Workflow

Each stage checkpoints to SQLite, so the pipeline resumes where it stopped.

Every field must cite a source URL and a verbatim quote — anything unevidenced becomes UNKNOWN by construction. Sources are ranked official developer docs first. Fields below 0.75 confidence trigger an independent second pass that never sees the first pass's reasoning, and cited quotes are re-checked against the live page. Where a human was needed: the accuracy audit, 5 unresolved apps, and ambiguous gating tiers.

Pipeline Limitations

  • Unresolved apps are preserved as UNRESOLVED because the evidence collected was insufficient — the pipeline never fills gaps with plausible guesses.
  • Research runs on a free-tier token budget; token-dense documentation pages are truncated to fit the model's context allowance, which can reduce extraction depth for some apps.
  • Findings reflect public documentation at run time (2026-07-17); APIs, pricing tiers and MCP availability change.
